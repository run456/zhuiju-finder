技术实现：链路是这样的

实测挖到的接口，讲清楚链接从哪来。

步骤接口 / 处理得到什么
搜影片GET juhebd.com/q/index?k=片名影片列表 + 详情页 id（如 0lj0）
取资源GET res.juhebd.com/api/rl?id=0lj0Base64 编码的数据
解码Base64 → JSON真实 magnet:?xt=urn:btih:... 磁力链 + 文件名 + 大小
🎯 实测结果：搜"奥德赛"第一部影片（id=0lj0）拿到 129 条磁力链接 + 夸克/迅雷网盘链接，含清晰的文件名和 GB 大小——和你截图里的界面一致。

⚠️ 补充：这类资源站的搜索页和接口可能改版或加反爬，届时抓取逻辑需相应调整；链接有效性由第三方决定，工具只做索引展示，不托管任何内容，请合规使用。
4

真实工具怎么用

  1. 执行 docker compose up -d --build 启动工具
  2. 打开 http://服务器IP:8000
  3. 输入片名点"搜索"，列出影片列表
  4. 点一部影片，列出它的全部真实磁力/网盘链接
  5. 按类型筛选（仅磁力 / 仅夸克），点"复制"直接拿链接
  6. 磁力链接点"打开"会自动复制，粘贴到迅雷/qBittorrent 等下载工具即可
